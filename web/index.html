AIserver Diffusers · H3 视频生成文生视频 / 参考生成 — 公网开放，无需鉴权，Diffusers 推理引擎

服务总览

服务基址 ，当前对公网开放，无鉴权、无频率限制。调用流程：POST /v1/jobs 提交任务 → 返回 job_id → 轮询 GET /v1/jobs/{id} → 成功后从 GET /v1/jobs/{id}/result 下载产物。模型状态以 /v1/models 返回为准。

接口一览

方法路径说明
GET/health服务存活检查
GET/ready推理运行时就绪状态与能力（任务 / 档位 / 几何）
GET/v1/models可用模型、任务与状态
POST/v1/files上传参考图片，返回 file_id，上限 2 GiB
POST/v1/jobs提交生成任务，202 返回 job_id 与 poll_url
GET/v1/jobs/{job_id}查询任务状态与结果信息
POST/v1/jobs/{job_id}:cancel取消仍在排队（queued）的任务
GET/v1/jobs/{job_id}/result下载产物 MP4
GET/v1/jobs分页浏览历史生成记录（本页“生成记录”所用）

任务状态流转：queued → starting → running → succeeded / failed；排队中可取消。其他文档：Swagger UI · ReDoc · openapi.json · llms.txt · 完整 API 指南

通用请求格式

请求体为 JSON，顶层字段：model（必填）、task（必填）、input（含 prompt / references）、parameters（时长、档位、步数、seed 等）、options（仅 priority）。额外顶层字段会被拒绝。

{
  "model":      "minimax-h3",            // 必填，唯一可用模型
  "task":       "text_to_video",         // 必填，text_to_video / ref2av
  "input":      {"prompt": "..."},       // 提示词；ref2av 附加 references
  "parameters": {"width": 512, "height": 320, "duration_seconds": 5.17,
                 "steps": 20, "profile": "quality", "seed": 12345},
  "options":    {}
}

提交（响应 202）

curl -X POST http://minixm.minapp.xin:8188/v1/jobs \
  -H 'Content-Type: application/json' \
  -d '{"model":"minimax-h3","task":"text_to_video","input":{"prompt":"A red tram crossing a rainy city at night, cinematic, realistic."},"parameters":{"duration_seconds":5.17,"width":512,"height":320,"steps":20,"profile":"quality"}}'
{
  "job_id": "job_xxxxxxxxxxxxxxxx",
  "status": "queued",
  "model": "minimax-h3",
  "task": "text_to_video",
  "created_at": "2026-10-22T12:00:00+00:00",
  "poll_url": "/v1/jobs/job_xxxxxxxxxxxxxxxx"
}

轮询与下载

JOB_ID="job_xxxxxxxxxxxxxxxx"
BASE="http://minixm.minapp.xin:8188"

while true; do
  STATUS=$(curl -s "$BASE/v1/jobs/$JOB_ID" | python3 -c 'import json,sys;print(json.load(sys.stdin)["status"])')
  echo "$STATUS"
  case "$STATUS" in
    succeeded|failed|cancelled) break ;;
  esac
  sleep 5
done

curl -f "$BASE/v1/jobs/$JOB_ID/result" -o output.mp4

模型调用方法

常见错误码

错误码含义
UNKNOWN_MODEL模型 ID 未登记（仅 minimax-h3）
UNSUPPORTED_TASK该服务不支持的任务类型
MODEL_NOT_READY工作流尚未通过验证（HTTP 503）
UNSUPPORTED_INPUT / UNSUPPORTED_OPTIONSinput / options 中出现未开放字段
INVALID_PROMPTprompt 为空或超过 2,000 字符
UNSUPPORTED_DURATION时长需为 5–15 秒的数值
INVALID_DIMENSIONS宽高需为 32 的倍数且面积 ≤983,040
UNVERIFIED_GEOMETRY宽高×帧数组合未通过验收（当前仅 512×320，5–15 秒帧槽）
UNVERIFIED_PROFILE档位 / 步数组合未通过验收（quality ≥20 步，turbo 档固定步数）
INVALID_STEPSsteps 需为 4–64 的整数
INVALID_SEEDseed 必须是 JSON 整数
INVALID_REFERENCE / REFERENCE_REQUIRED / REFERENCE_LIMITreferences 结构、数量或必填项不满足
INPUT_FILE_NOT_FOUND / INPUT_TOO_LARGE文件引用无效（file_id 为 32 位十六进制）或超过 2 GiB
UNVERIFIED_REFERENCE视频 / 音频参考工作流尚未开放（图片参考最多 1 张）
UNVERIFIED_LORALoRA 支持未通过验证
QUEUE_FULL任务队列已满（HTTP 429）
JOB_NOT_FOUND任务不存在（HTTP 404）
RESULT_NOT_READY / RESULT_NOT_FOUND任务未成功或产物缺失
INFERENCE_FAILED入队后推理失败，见任务记录中的 error_message

提交校验错误返回 HTTP 400 + {"detail":{"code":...,"message":...}}；请求体不符合顶层 schema 返回 HTTP 422。
